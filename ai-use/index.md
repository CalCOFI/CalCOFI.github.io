<h1>How we use AI</h1>

<p>We use an AI assistant (Claude, by Anthropic) to help build and write this site. It helps write the code that builds the dataset pages and drafts some of the text on them, such as short descriptions synthesized from original data sources. All data, measurements and metadata come from the data providers.</p>

<p>If you spot a mistake, write to <a href="mailto:data@calcofi.io">data@calcofi.io</a>.</p>
