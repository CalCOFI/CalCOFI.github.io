<h1>How we use AI</h1>

<p>We use an AI assistant (Claude, by Anthropic) to help build and write this site. It helps write the code that builds the pages, and it helps draft some of the words on them, such as a dataset's plain name and short description.</p>

<p>The data and the measurements come from the data providers. The words that describe a dataset are kept with each provider's metadata in the <a href="https://github.com/CalCOFI/workflows">workflows repository</a>, where a provider can read and correct them; some are still drafts waiting for their provider's review. The site shows what a release carries and adds no facts of its own.</p>

<p>If you spot a mistake, write to <a href="mailto:{{ site.contact_email | escape }}">{{ site.contact_email | escape }}</a>.</p>
