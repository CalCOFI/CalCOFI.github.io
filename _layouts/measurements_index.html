Everything CalCOFI has measured in the water and the air above it — temperature and salinity from the bottle casts of 1949 to this year's CTD profiles, nutrients, carbon, pigments and light, the underway weather, the picoplankton counted by flow cytometry — keyed to one name, so the same measurement means the same thing in every dataset. Start from the overview below, search, filter by category, or start from a dataset; every measurement has its own page.

{%- comment -%} how the count works, every number read from the record (Ben, 2026-09-10: the total must be plain, and how a shared NERC concept is what folds two datasets' series into one measurement) {%- endcomment -%}

A measurement is one quantity under one name; a series is one dataset's column for it. Two datasets' series count as one measurement only where they carry the same NERC P01 concept for the same kind of sample — {{ c.n_unified }} do today: {%- for u in mm.unified %} {{ u.label }}{% unless forloop.last %},{% endunless %}{% endfor %} — so {{ c.series }} series make {{ c.measurements }} measurements. {{ c.n_p01 }} of the {{ c.measurements }} carry a NERC P01 concept; {{ c.n_no_p01 }} carry none and keep their own names, because an empty concept means no concept says exactly this, never that nobody looked.

The machine-readable form is one JSON per measurement (/measurements/{key}.json) and sitemap.xml.

    Which measurements, in which datasets, in which years

    One row per measurement, one bar per dataset that carries it, 1949 on the left and the release year on the right; hover a bar for the dataset, its series, years, values, sampling events and depths. Two bars in a row are two datasets measuring the same thing — the bottle's temperature and the CTD's temperature_ave, comparable across datasets — never a dataset's own bottle samples beside its sensor (the CTD files' btl_* series stay their own rows, so the bottle dataset is not counted twice). The values column is the release grain (obs_env); the CTD and METS full-resolution tables carry more behind the same names.
