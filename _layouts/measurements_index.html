A measurement is one quantity under one name; a series is one dataset's column for it. Two datasets' series count as one measurement only where they carry the same NERC P01 concept for the same kind of sample — {{ c.n_unified }} do today: {%- for u in mm.unified %} {{ u.label }}{% unless forloop.last %},{% endunless %}{% endfor %} — so {{ c.series }} series make {{ c.measurements }} measurements. {{ c.n_p01 }} of the {{ c.measurements }} carry a NERC P01 concept; {{ c.n_no_p01 }} carry none and keep their own names, because an empty concept means no concept says exactly this, never that nobody looked.

Values: {{ c.obs_env_rows_m }} M at the release grain (rows of obs_env, one measurement × one sample) {%- if mm.counts.sample_measurement_rows > 0 %}, {{ c.sample_measurement_rows }} one per cast (rows of sample_measurement: the mixed-layer depths and the chlorophyll maximum and integral){% endif %}, {{ c.full_rows_m }} M with the two full-resolution supplementals, obs_ctd_full and obs_mets_full.

The machine-readable form is one JSON per measurement (/measurements/{key}.json) and sitemap.xml.

Which measurements, in which datasets, in which years

One row per measurement, one bar per dataset that carries it, 1949 on the left and the release year on the right; hover a bar for the dataset, its series, years, values, sampling events and depths. Two bars in a row are two datasets measuring the same thing — the bottle's temperature and the CTD's temperature_ave, comparable across datasets — never a dataset's own bottle samples beside its sensor (the CTD files' btl_* series stay their own rows, so the bottle dataset is not counted twice).
