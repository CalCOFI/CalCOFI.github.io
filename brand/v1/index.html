calcofi.io brand v1

One source for the theme, the header chrome, the logo, the favicon and the icon set that every CalCOFI product shares — served from https://calcofi.io/brand/v1/. v1 is the brand in force; it is frozen once adopted: token additions are fine, anything that changes how an existing page looks or behaves is v2, and consumers opt in. The rule is checked weekly, not assumed (scripts/check_brand.py).

v1 · in forcev2 · proposed (the SIO look)

The contract, in one breath

  1. Theme resolution — ?theme=dark|light on any URL → cookie cc_theme on .calcofi.io → localStorage.theme → dark. theme.js sets data-theme / data-bs-theme / data-md-color-scheme on <html> and fires cc:theme; maps, Plotly and Mermaid restyle on it. Never key on prefers-color-scheme.
  2. The header — logo far left → https://calcofi.io; the product's title beside it → its own root; the theme toggle at the right shows what a click switches to (a sun while the page is dark, a moon-in-sun while it is light). Where a framework owns the bar (Quarto, pkgdown, mkdocs, bslib) the logo goes in its brand slot and its toggle is bridged — never two bars, never two toggles.
  3. The favicon set, except calcofi4r (hex) and calcofi4py (squircle).
  4. ?tour=off suppresses any guided tour, so live_url?theme=<t>&tour=off is a deterministic screenshot.

Icons

48 glyphs on the 24-px grid — Material Design Icons (Pictogrammers, Apache-2.0) plus the bespoke marine set (drawn by CalCOFI/explore scripts/icon_glyphs.py): cat-* the twelve data categories, lens-* the Explorer's lenses, realm-*, ui-*. icons.css exports each as a mask (<i class="cc-i cc-i-cat-fish"></i> draws it in the text colour on any page); icons/calcofi-icons.svg is the same set as a sprite for same-origin <use>.
