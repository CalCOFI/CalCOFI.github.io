# calcofi.io/stac/ — STAC Browser over the CalCOFI catalog

A build of [radiantearth/stac-browser](https://github.com/radiantearth/stac-browser) pointed at the
static STAC catalog the release writes to `gs://calcofi-db/stac/` (plan 2026-09-05 § D-5.3, WS-M1).
Nothing here is generated at request time: this directory is a committed `dist/`, and the catalog it
reads is regenerated by `release_database.qmd` (`calcofi4db::build_stac()`, ≥ 4.3.0) on every
release. A new release adds one **item** per dataset collection; the browser needs no rebuild for it.

- Catalog root: <https://storage.googleapis.com/calcofi-db/stac/catalog.json>
- One collection per public dataset (16 at v2026.09.05) + one per spatial layer (19)
- One item per release under each dataset collection, whose assets are that dataset's parquet
  objects, its CF netCDF, its ERDDAP pages and its ISO 19115 record
- The record the catalog is generated from: <https://calcofi.io/datasets/>

## Rebuilding

Only needed to take a new stac-browser version or change its configuration.

```bash
git clone --depth 1 https://github.com/radiantearth/stac-browser
cd stac-browser
# config.js — the four lines that differ from upstream:
#   catalogUrl:          "https://storage.googleapis.com/calcofi-db/stac/catalog.json"
#   catalogTitle:        "CalCOFI Data Catalog"
#   allowExternalAccess: false        # locked to the CalCOFI catalog
#   pathPrefix:          "/stac/"
#   historyMode:         "hash"       # GitHub Pages has no rewrites
npm install
npm run build:minimal                 # `minimal` = no source maps (51 MB -> 17 MB)
rsync -a --delete dist/ <this repo>/stac/
```

Then re-apply the two edits `dist/index.html` carries here: the calcofi.io favicon links and the
`meta description`. The brand **stylesheet** is deliberately not loaded — it would restyle a
third-party app unpredictably; the favicon set is the part that is safe and makes the tab
recognisable (brand contract: `brand/v2/README`).

Built 2026-09-05 from stac-browser 5.1.0-rc.1 (`e2d14b0`).

## Notes

- `historyMode: "hash"` — URLs look like `/stac/#/collections/{dataset_key}/collection.json`.
  GitHub Pages cannot rewrite unknown paths onto `index.html`, and a deep link that 404s is worse
  than a `#`.
- The catalog is fetched cross-origin from `storage.googleapis.com`, which answers
  `access-control-allow-origin: *` (checked 2026-09-05).
- A staging release writes `gs://calcofi-db/stac-staging/` instead, so a rehearsal never rewrites
  what this browser reads.
